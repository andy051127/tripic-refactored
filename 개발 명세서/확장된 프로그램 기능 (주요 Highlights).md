실시간 데이터 연동: ValueNotifier를 사용하여 글을 쓰거나, 팔로우를 하거나, 정보를 수정하면 앱의 모든 화면(홈, 프로필, 설정 등)에 즉시 반영됩니다.

통합된 사진/위치 기능: 게시물 작성 시 실제 갤러리 사진을 가져오고, 지도에서 위치를 선택하여 저장할 수 있습니다.

상호작용(Interaction):

좋아요/댓글/스크랩: 활동 내역에 자동 저장되고, 보관함에서 확인 가능합니다.

차단/신고/숨기기: 해당 게시물이 피드에서 즉시 사라지고, 차단 목록에서 관리됩니다.

팔로우: 팔로잉 숫자가 실시간으로 연동됩니다.

다양한 모달 UI: 날짜, 시간, 친구 선택 등 각 상황에 최적화된 바텀 시트 UI를 제공하여 사용자 경험을 높였습니다.
