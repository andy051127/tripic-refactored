## 🔄 주요 이동 흐름 요약 ##

```

splash_screen (2초 대기) → login_screen ┬→ 회원가입 버튼 → signup_screen → profile_creation_screen → home_screen
                                        ├→ 이메일 로그인 → home_screen
                                        ├→ 카카오 로그인 (UI만) → [미구현]

┌─────────────────────────────────────────────────────────────┐

│                  │                    ├→ 좋아요 버튼 → 실시간 카운트 업데이트 (Firestore)
│                  │                    ├→ 댓글 버튼 → comment_modal (실시간 댓글 작성/표시)

│                  │                    ├→ 지도 버튼 → map_screen (게시물 위치 표시)
│                  │                    ├→ 북마크 → 보관함 저장
│                  │                    └→ 더보기 → 팔로우/신고/차단/숨기기/삭제

│                          │                                    ├→ 국가 선택 → 지도 모달
│                          │                                    ├→ 비행편 입력 → 시간 선택 모달
│                          │                                    ├→ 숙소 입력
│                          │                                    ├→ 인원 추가 → friend_list_screen (선택모드)
│                          │                                    └→ 준비물 추가 → 체크박스 모달
│                          └→ 계획 카드 클릭 → travel_plan_detail_screen → 수정 → travel_plan_setup_screen
│
│ 탭3: + 버튼 (중앙) → photo_picker_screen (게시물 작성)
│
│ 탭4: community_screen ┬→ + 버튼 → community_write_screen ┬→ 사진 선택 → 갤러리
│                       │                                  ├→ 장소 선택 → 지도 모달
│                       │                                  ├→ 날짜 선택 → 달력 모달
│                       │                                  └→ 인원 선택 → friend_list_screen (선택모드)

│                       │                                        ├→ DM 보내기 → chat_detail_screen

[3️⃣ 게시물 작성 플로우 상세]

photo_editor_screen ┬→ 사진 편집 버튼 → 이미지 에디터 → 편집 완료
                    ├→ 사진 추가 → photo_picker_screen
                    ├→ 사진 삭제 → 목록에서 제거
                    ├→ 함께 있는 사람 + 버튼 → friend_list_screen (선택모드) ┬→ 친구 다중 선택
                    │                                                      └→ 확인 → 태그 추가됨
                    ├→ 위치 선택 → map_screen (선택 모드) ┬→ 현재 위치 버튼
                    │                                    ├→ 지도 탭 선택 → 위치 반환
                    │                                    └→ Google Places API 검색 → 장소 검색
                    └→ 다음 버튼 → write_post_screen

write_post_screen ┬→ 제목 입력
                  ├→ 내용 입력
                  ├→ 태그된 친구 표시 (photo_editor_screen에서 전달)
                  ├→ 국가 정보 자동 저장 (위치 기반)
                  ├→ 공개 범위 설정 → friend_list_screen (특정친구 선택)
                  └→ 업로드 → Firebase Storage + Firestore → home_screen (게시물 추가됨)

[4️⃣ 검색 및 프로필 탐색 상세]
search_screen ┬→ 사용자 검색 → other_user_profile_screen ┬→ 팔로우/언팔로우
              │                                          ├→ 게시물 클릭 → 게시물 상세
              │                                          ├→ 팔로워 클릭 → follow_list_screen
              │                                          ├→ 팔로잉 클릭 → follow_list_screen
              │                                          └→ DM 버튼 → chat_detail_screen
              └→ 장소 검색 → map_search_screen ┬→ 검색창 입력 → 지역명 검색
                                              ├→ 친구 이름 검색
                                              └→ 위치 선택 → 이전 화면으로 반환

follow_list_screen ┬→ 팔로워 탭 → 사용자 리스트 → other_user_profile_screen
                   └→ 팔로잉 탭 → 사용자 리스트 → other_user_profile_screen

[5️⃣ 메시지 상세]
message_list_screen ┬→ 채팅방 클릭 → chat_detail_screen ┬→ 메시지 입력/전송 (Firestore 실시간)
                    │                                   ├→ 게시물 공유 버튼 → share_post_screen → 게시물 선택 → 전송
                    │                                   ├→ 공유된 게시물 클릭 → post_detail_screen
                    │                                   └→ 상대방 프로필 이미지 클릭 → other_user_profile_screen
                    ├→ + 버튼 → friend_list_screen (일반모드) → 친구 선택 → chat_detail_screen 생성
                    └→ 즐겨찾기 탭 → 즐겨찾기 채팅방 리스트

friend_list_screen ┬→ [일반 모드] 친구 클릭 → chat_detail_screen 생성
                   ├→ [선택 모드] 여러명 선택 → 확인 → 이전 화면으로 반환 (선택 정보 전달)
                   ├→ 검색 기능 → 친구 이름 필터링
                   └→ + 버튼 → add_friend_screen ┬→ 사용자 이름으로 검색 → 친구 추가
                                                  └→ 초대 링크 생성/공유

[6️⃣ 지도 기능 상세]
map_screen (map_detail_screen) ┬→ 내 위치 표시 (GPS)
                                ├→ Firestore 게시물 마커 표시 (실시간)
                                ├→ 마커 클릭 → 게시물 미리보기 팝업 ┬→ 첫 번째 사진 표시
                                │                                  ├→ 실시간 좋아요/댓글 수
                                │                                  ├→ 사용자 프로필 이미지
                                │                                  └→ 클릭 → 게시물 상세 [미구현]
                                ├→ 검색 기능 ┬→ 사용자 이름 검색 → 해당 위치로 이동
                                │            │  └→ 게시물 탐색 버튼 (↑/↓) → 사용자의 다른 게시물 순환
                                │            └→ Google Places API → 장소 검색 → 해당 지역으로 이동
                                ├→ 지도 탭 선택 (선택 모드) → 위치 반환
                                ├→ 지도 이동/줌
                                ├→ userId 파라미터 지원 (특정 사용자 게시물만 표시)
                                └→ 뒤로가기 → 이전 화면

프로필 화면 지도 탭 ┬→ 내 위치 미리보기 표시
                    └→ 클릭 → map_screen (userId 전달) → 내 게시물만 표시

                │                                      └→ 팔로우 알림 설정

                   │                                    ├→ 국가 선택 → 검색 또는 지도 모달
                   │                                    ├→ 비행편 정보 ┬→ 출발 시간 선택 모달
                   │                                    │              └→ 도착 시간 선택 모달

                   │                                    ├→ 준비물 추가 → 입력 모달 ┬→ 항목 추가

                   │                                    └→ 저장 → travel_plan_screen (계획 추가됨)

                 │            │                                  ├→ 장소 선택 → 지도 모달

                 └→ 동행 탭 ┬→ 동행 찾기 게시글 리스트
                           ├→ + 버튼 → community_write_screen (동행모드)

[🔟 로그인 화면 상세]
login_screen ┬→ 회원가입 버튼 → signup_screen ┬→ 이메일 입력
             │                               ├→ 비밀번호 입력
             │                               ├→ 이름 입력
             │                               ├→ 생년월일 입력
             │                               └→ 가입 완료 → profile_creation_screen ┬→ 프로필 사진 선택
             │                                                                      ├→ 소개 입력
             │                                                                      └→ 완료 → home_screen
             ├→ 이메일 로그인 ┬→ 이메일 입력
             │                ├→ 비밀번호 입력
             │                └→ 로그인 → Firebase Auth → home_screen
             ├→ 카카오 로그인 버튼 (UI만) → [미구현]
             ├→ 네이버 로그인 버튼 (UI만) → [미구현]
             └→ 구글 로그인 버튼 (UI만) → [미구현]

[11. 프로필 화면 상세]
profile_screen ┬→ 프로필 사진 클릭 → 갤러리/카메라 선택 → 사진 선택 → Firebase Storage 업로드 → 프로필 업데이트
               ├→ 프로필 정보 표시 ┬→ 이름
               │                  ├→ 소개
               │                  ├→ 국기
               │                  └→ 통계 (게시물 수/팔로워/팔로잉)
               ├→ 국가 필터 배너 (TabBar 아래) → 특정 국가 선택 → 해당 국가 게시물만 표시
               ├→ + 버튼 → photo_picker_screen → photo_editor_screen → write_post_screen → home_screen
               ├→ 햄버거 버튼 → member_info_screen ┬→ 이메일 수정 → 입력 모달 → 저장
               │                                   ├→ 전화번호 수정 → 입력 모달 → 저장
               │                                   ├→ 생년월일 수정 → 날짜 선택 → 저장
               │                                   ├→ 성별 수정
               │                                   ├→ 국적 수정
               │                                   └→ 기타 정보 수정
               ├→ 설정 버튼 → settings_screen (상세 흐름은 [7️⃣ 설정 메뉴 상세] 참조)
               ├→ 팔로워 숫자 클릭 → follow_list_screen (팔로워 탭) ┬→ 사용자 클릭 → other_user_profile_screen
               │                                                   └→ 팔로우/언팔로우 버튼
               ├→ 팔로잉 숫자 클릭 → follow_list_screen (팔로잉 탭) ┬→ 사용자 클릭 → other_user_profile_screen
               │                                                   └→ 언팔로우 버튼
               ├→ 지도 탭 ┬→ 내 위치 미리보기 표시
               │          └→ 클릭 → travel_record_map_screen → 내 여행 기록 지도
               ├→ 게시물 그리드 클릭 → my_posts_detail_screen ┬→ 국가 필터 배너
               │                                              ├→ PostItem 방식 표시
               │                                              └→ 실시간 좋아요/댓글/북마크
               └→ 로그아웃 버튼 → Firebase Auth.signOut() → login_screen

other_user_profile_screen ┬→ 프로필 정보 표시 (팔로우/언팔로우/메시지 버튼)
                          ├→ 국가 필터 배너 (팔로우/메시지 버튼 위) → 특정 국가 선택 → 필터링
                          ├→ 지도 탭 → travel_record_map_screen (해당 사용자 여행 기록)
                          ├→ 게시물 그리드 클릭 → other_user_posts_detail_screen ┬→ 국가 필터 배너
                          │                                                      ├→ PostItem 방식 표시
                          │                                                      └→ 실시간 좋아요/댓글
                          └→ DM 버튼 → chat_detail_screen

post_detail_screen (DM/보관함) ┬→ 프로필 이미지/이름 클릭 → other_user_profile_screen
                               ├→ 국가 아이콘 표시 (국기 + 국가코드)
                               ├→ 함께한 사람 클릭 → 해당 친구 프로필로 이동
                               ├→ 실시간 좋아요/댓글
                               └→ 북마크/공유
